# AbyssCrate Fabric 26.3 — Etapa 2 (experimental)

Aceasta versiune adauga un registru persistent de tipuri de crate.

Comenzi: `/crate create <nume>` si `/crate list`.

Datele sunt salvate in `config/shadowcrates/crates.properties` pe server.

**Nu sunt implementate**: plasarea crate-urilor, cheile, recompensele, GUI-ul si animatiile.

Atentie: comenzile nu au inca restrictii de permisiune; testeaza doar pe un server privat/de test. Nu instala pe serverul public.

Pentru GitHub: copiaza fisierele modificate in acelasi folder din repository. Workflow-ul existent va compila proiectul.
